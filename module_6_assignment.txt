1. I'm applying the RAII idiom. Mainly, changing all memory allocation practices to using sharepointers instead of new and delete. So it deletes the object automatically.

2. The XML application is not that different from an IDE where you can view the list of files you have and have a text editor in the center. We can have a tool bar that handles the create and save functions, the open and edit functions can come automatically when you select and open a file. And you can open or view multiple XML files at the same time using tabs on top of the screen. It may not need a side bar that contains all the files in a folder like an IDE, but rather it can just open files independently through the open function. 

Essentially that will create a sentence like this:
Interaction Style->Explorable Interface->Single Setting->Menu Bar (which contains the file, edit, selection, view etc. that has functions such as opening a file through the file explorer, undo/redo, the regular editing functions)
From Single Setting->Palette (for the tabs)
From Single Setting->Goal oriented areas (the text editor area)

This should cover all the necessary functions of the XML application.

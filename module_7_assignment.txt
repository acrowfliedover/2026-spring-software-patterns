Do I understand what is needed for the assignment? 

Client	Any code that uses the Xerces DOM API: it holds/calls DOMDocument*, DOMNode*, etc. (e.g. doc->createElement(...), node->getChildNodes()). It only knows the Target interface.
Target	The Xerces DOM interfaces: DOMNode, DOMDocument (and, if you expose elements/text/attrs, DOMElement, DOMText, DOMAttr) from DOMNode.hpp / DOMDocument.hpp. This is the type the Client depends on.
Adapter	Your wrapper classes that implement the Target (e.g. inherit DOMNode/DOMDocument) and hold a reference to the project’s DOM. They translate each Target method into calls on the Adaptee and do type conversion.
Adaptee	The project’s DOM interface + implementation: dom::Node, dom::Document, and the real objects (Node_Impl, Document_Impl, Element, Text, Attr). This is what actually stores and manipulates the tree.
